## x86, x86-64 (CISC) - Complex Instruction Set Computer
- One core is very powerful and can productively do a consuming task Fit for games, video-editing or 3D design. (ex. AMD Ryzen, Intel)
- Has separate processors and components.
- Used in computers and laptops.
- Backwards compatibility, standard. Compatible with all old software.
## ARM, RISC-V (RISC) - Reduced Instruction Set Computer
- Very effective for multicore = multiprocessing/multitasking. (ex. new Apple M-series processors)
- Usually has system on cip (SoC) - processors, graphics, memory... are all on one crystal. It makes them smaller and more energy effective.
- Used for smarthones, small devices, IoT or light(weight and tasks) laptops, tablets.
